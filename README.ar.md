# 🚀 Free Proxy — أنشئ مجمّع البروكسي المجاني الخاص بك بأمر واحد

> شغّل **أمرًا واحدًا** على خادم صغير خارج بلدك، فيقوم تلقائيًا بسحب المئات من المنافذ المجانية من مصادر العقد العامة (VPNGate)، ويقيس السرعة الفعلية، ويختار بذكاء أسرع خط، ليوفّر لك بروكسي **SOCKS5 / HTTP** ثابتًا. عند انقطاع أي عقدة يتم التبديل تلقائيًا، دون حاجة إلى مراقبتك المستمرة.

**لمن هذه الأداة؟**

- من يريد منفذ بروكسي **خاصًا به وتحت سيطرته**، بدلًا من تسليم حركة بياناته إلى مطار (خدمة) شخص آخر.
- من لديه (أو ينوي شراء) خادم VPS خارج بلده، ويرغب في تحويله إلى بوابة بروكسي مؤتمتة بالكامل.
- من لا يريد العناء مع الإعدادات المعقدة — **تثبيت بأمر واحد، وبضع نقرات على صفحة الويب ليبدأ العمل**.

## ✨ أبرز المزايا الأساسية

- 🔌 **النشر بأمر واحد**: التبعيات والخدمة والتشغيل التلقائي عند الإقلاع، كلها تُنجز تلقائيًا، حتى المبتدئ يستطيع البدء.
- 🌍 **اكتشاف تلقائي + قياس سرعة حقيقي**: يسحب المئات من العقد من المصادر العامة، ويختبر الاتصال والزمن الفعلي، ويختار الأسرع تلقائيًا.
- ♻️ **تبديل تلقائي عند الانقطاع**: العقد المجانية غير مستقرة؟ تتم إعادة الاتصال والتبديل في الخلفية تلقائيًا للحفاظ على البروكسي متصلًا دائمًا.
- 🧩 **SOCKS5 / HTTP على المنفذ نفسه**: منفذ واحد `9527` يخدم الجميع، مع التعرف التلقائي على البروتوكول من أول بايت.
- 🖥️ **لوحة تحكم ويب بسيطة**: مجمّع العقد وحالة البوابة والسجلات والاستراتيجية، كلها في شاشة واحدة.
- 📦 **ملف واحد بلا تبعيات**: ثنائي ساكن واحد، يتضمّن الواجهة الأمامية وقاعدة البيانات مدمجتين، يعمل فور نزوله.

## ⚡ النشر في ثلاث خطوات (نسخة المبتدئ حقًا)

لنفترض أنك اشتريت خادم VPS بالفعل وحصلت على **عنوان IP للخادم** و**كلمة مرور root**.

**الخطوة 1 · تسجيل الدخول عبر SSH إلى خادم VPS**

```bash
ssh root@你的服务器IP
```

**الخطوة 2 · التثبيت بأمر واحد**

```bash
bash <(curl -Ls https://raw.githubusercontent.com/masteralanlab/free-proxy/main/install.sh)
```

سيقوم السكربت تلقائيًا بـ: تنزيل البرنامج المناسب للمعمارية ← تثبيت تبعيات النظام (مثل openvpn) ← تسجيل خدمة التشغيل التلقائي عند الإقلاع ← بدء التشغيل. انتظر حتى ينتهي فحسب، دون أي تفاعل خلال العملية.

**الخطوة 3 · سجّل عنوان الإدارة واسم المستخدم وكلمة المرور**

بعد التثبيت الأول، سيقوم السكربت **مباشرة بطباعة** المسار واسم المستخدم وكلمة المرور المولّدة عشوائيًا:

```text
URL:       http://<你的服务器IP>:39527/xxxxxxxxxxxx/
Username:  xxxxxxxx
Password:  xxxxxxxx
```

> 🔑 يتم توليد المسار واسم المستخدم وكلمة المرور عشوائيًا عند **التثبيت الأول فقط**. احفظها فورًا لأن كلمة المرور لا يمكن استرجاعها لاحقًا.
> 🔒 تحتفظ التحديثات اللاحقة بالمسار واسم المستخدم وكلمة المرور. لتغييرها صراحةً استخدم لوحة الإدارة أو `free-proxy install --rotate-admin`.

✅ **تم!** الخدمة تعمل الآن في الخلفية وتقوم تلقائيًا بسحب العقد وقياس السرعة والاتصال. لننتقل الآن إلى كيفية الاستخدام.

## 🌐 كيفية استخدام البروكسي / الوصول إلى لوحة تحكم الويب

تستمع الخدمة افتراضيًا على `0.0.0.0`، وتتضمّن **مفتاح «الوصول من الخارج»** (يمكن تبديله في أي وقت من صفحة «الاستراتيجية» في اللوحة، **يسري فورًا دون إعادة تشغيل**). أما الوصول المحلي وعبر نفق SSH فيبقى **متاحًا دائمًا** ولا يتأثر بهذا المفتاح.

### لوحة تحكم الويب: يُسمح بالوصول من الخارج افتراضيًا ✅

محمية بحماية مزدوجة: تسجيل دخول + مسار مفتاح عشوائي، فيمكنك فتحها من الخارج فور التثبيت. افتح في المتصفح العنوان الذي طبعه `free-proxy credentials`:

```text
http://你的服务器IP:39527/<你的安全路径>/
```

إن لم تكن بحاجة إلى الوصول العام، يمكنك إيقاف مفتاح الوصول الخارجي الخاص بها في اللوحة، أو استخدام نفق SSH بدلًا منه (انظر أدناه).

### منفذ البروكسي: محلي فقط افتراضيًا 🔒

لتجنّب أن يصبح **«بروكسي مفتوحًا»** متاحًا للجميع، يخدم البروكسي الجهاز المحلي فقط افتراضيًا. للاستخدام من الخارج، خطوتان:

1. **Configure proxy credentials in the dashboard**: open “Policy → Web and proxy service”, then enter a proxy username and a new password.
2. **التفعيل من اللوحة**: ادخل إلى لوحة الويب «الاستراتيجية ← الوصول من الخارج»، وفعّل «السماح بالوصول الخارجي لمنفذ البروكسي» ثم احفظ.

بعد ذلك يمكنك الاستخدام في تطبيقات جهازك المحلي: `socks5://用户名:密码@你的服务器IP:9527`.

> 🔒 الاستخدام الأكثر تحفظًا (دون فتح أي وصول عام إطلاقًا): أوقف من اللوحة الوصول الخارجي للوحة الويب، واستخدم نفق SSH بدلًا منه —
> `ssh -L 39527:127.0.0.1:39527 -L 9527:127.0.0.1:9527 root@你的服务器IP`، ثم افتح محليًا `127.0.0.1`.

### التحقق من أن البروكسي يعمل

```bash
curl --proxy socks5h://127.0.0.1:9527 https://api.ipify.org   # 返回的应是"VPN 出口 IP",而不是你 VPS 自己的 IP
curl --proxy http://127.0.0.1:9527   https://api.ipify.org
```

إذا رأيت عنوان IP مختلفًا عن عنوان خادم VPS الخاص بك، فهذا يعني أن البروكسي يقوم بالفعل بإعادة التوجيه عبر منفذ خروج VPN 🎉

## 🖱️ كيفية استخدام لوحة تحكم الويب

1. افتح عنوان الإدارة، وسجّل الدخول باسم المستخدم وكلمة المرور.
2. انقر على **«تحديث وفحص العقد»**، وانتظر قليلًا حتى يكتشفها ويقيس سرعتها ويتصل تلقائيًا بأسرع عقدة.
3. تُظهر لوحة **«البوابة»** عقدة الخروج الحالية وزمن الاستجابة وعنوان IP للخروج.
4. وجّه بروكسي تطبيقات جهازك المحلي إلى `127.0.0.1:9527` لتبدأ الاستخدام.

## ❓ الأسئلة الشائعة

- **لا يتصل / لا توجد عقد مؤقتًا؟** العقد المجانية (VPNGate) نفسها متذبذبة، وستقوم الخدمة بإعادة المحاولة والتبديل تلقائيًا. انتظر قليلًا، أو انقر مرة على «تحديث وفحص العقد» من اللوحة.
- **يظهر أنه يتطلب root / TUN؟** شغّله بصلاحية root، وتأكد من أن خادم VPS قد فعّل TUN/TAP. كل من **[BandwagonHost](https://cutt.ly/qywJNWzd)** / **[DMIT](https://cutt.ly/YywJIzY0)** بمعمارية KVM، ويدعمها افتراضيًا وجاهز للاستخدام مباشرة.
- **خادم VPS الخاص بي بمعمارية ARM؟** لا تقلق، فسكربت التثبيت يتعرف تلقائيًا على amd64 / arm64.
- **هل يمكن تشغيله على حاسوبي الخاص (macOS/Windows)؟** يمكن البناء والتطوير، لكن النفق الحقيقي وبروكسي الخروج يتطلبان Linux + root + TUN، فيرجى النشر على خادم VPS.

### واجهة سطر الأوامر الكاملة

```bash
free-proxy serve                 # 运行控制台 + 代理网关 + 后台任务

free-proxy uninstall             # 卸载服务与二进制,--purge-data 同时删数据(需 root)

free-proxy install-deps          # 仅安装 openvpn / iproute2 / procps(需 root)
free-proxy database-upgrade      # 执行数据库迁移
free-proxy admin-config ...      # 修改管理凭据与监听
free-proxy logs --lines 200      # 打印最近日志
```

### الإعداد

يكون ملف الإعداد في بيئة الإنتاج افتراضيًا `/etc/free-proxy/free-proxy.env` (يُنشأ بواسطة `free-proxy install`)، وتتوحّد متغيرات البيئة بالبادئة `FREE_PROXY_`. تقرأ جميع الأوامر الفرعية هذا الملف تلقائيًا (تكون أولوية متغيرات بيئة العملية أعلى؛ ويمكن تجاوز المسار عبر `FREE_PROXY_ENV_FILE`). أبرز الخيارات:

```text
FREE_PROXY_DATA_DIR=/var/lib/free-proxy
FREE_PROXY_DATABASE_URL=
FREE_PROXY_SQL_ECHO=false
FREE_PROXY_ALLOW_PROCESS_RESTART=true
FREE_PROXY_OPENVPN_COMMAND=openvpn
FREE_PROXY_OPENVPN_USERNAME=vpn
FREE_PROXY_OPENVPN_PASSWORD=vpn
FREE_PROXY_TUNNEL_INTERFACE=fpx0
FREE_PROXY_PROBE_DEVICE_PREFIX=fpx
FREE_PROXY_TEST_TUN_START=1
FREE_PROXY_TEST_TUN_END=64
FREE_PROXY_POLICY_ROUTING_TABLE=9527
```

> Web port, proxy port, credentials, discovery, maintenance, DNS, routing, and external-access options are managed in the dashboard and stored in SQLite.

للخوادم الصغيرة ضعيفة الإمكانات (مثل 1 نواة / 1G) يمكن تخفيض حِمل الفحص:

Use the dashboard to lower probe concurrency, discovery limit, and initial test count.

### ملخص API

جميع نقاط النهاية تحت بادئة المسار الآمن: `/{secret_path}/api/v1/...`. تُرجع العمليات طويلة الأمد `202 + Job`، وتُستطلع عبر `GET /jobs/{id}`.

```text
POST   /api/v1/auth/login        POST /api/v1/auth/logout
GET    /api/v1/auth/config       PUT  /api/v1/auth/credentials
GET    /api/v1/proxies           POST /api/v1/proxies/discover|refresh|probe
POST   /api/v1/proxies/{id}/probe|activate|favorite
GET    /api/v1/proxies/{id}/probes|config
GET    /api/v1/gateway/status    POST /api/v1/gateway/check|rotate    DELETE /api/v1/gateway/current
GET    /api/v1/pool/statistics   GET  /api/v1/jobs/{id}
GET    /api/v1/settings          PUT  /api/v1/settings
GET    /api/v1/system/status|diagnostics   POST /api/v1/system/dns/repair
GET    /api/v1/logs              GET  /api/v1/logs/export
```

### حزمة التقنيات

- **Go 1.23+**، وEcho v5 (الويب/API)، وsqlc + `modernc.org/sqlite` (Go خالص، دون CGO)، وgoose (ترحيلات مدمجة)، وcobra (CLI)، وlog/slog.
- الواجهة الأمامية **React 19 + Vite + Tailwind v4 + Zustand**، وتُدمج مخرجات البناء داخل الثنائي عبر `//go:embed`.
- تُجزّأ كلمات المرور بـ `scrypt`، مع مصادقة عبر مسار آمن عشوائي + كوكي الجلسة.

### البناء من المصدر

تحتاج إلى Go 1.23+ وbun.

```bash
make build        # 构建前端 + 静态二进制到 dist/free-proxy
make cross        # 交叉编译 linux amd64 / arm64
make test         # 运行 Go 测试
```

بما أنه لا يوجد CGO، يمكنك إنتاج ثنائي Linux مباشرة على macOS. انسخ مخرجات البناء المحلي إلى الجهاز الهدف ثم نفّذ `sudo ./free-proxy install` للنشر.

التحديث الحي أثناء التطوير:

```bash
cd frontend && bun install && bun run dev   # 前端热更新(配合下方 serve)
go run ./cmd/free-proxy serve                # 后端(首次会生成随机管理地址与密码)
```

### إصدار Release

يقوم `install.sh` بتنزيل `free-proxy-linux-{amd64,arm64}` من GitHub Releases، ويبنيه ويصدره تلقائيًا `.github/workflows/release.yml` عند **دفع وسم إصدار**:

```bash
git tag v1.0.0
git push origin v1.0.0      # 触发 Action:构建前端 + 交叉编译 → 发布 Release(含 SHA256SUMS)
```

يجب أن يبدأ الوسم بـ `v`. بعد اكتمال الإصدار، سيصيب تنزيل `latest` في `install.sh` هذا الثنائي.
