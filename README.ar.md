# 🚀 Free Proxy — أنشئ تجمّع البروكسي المجاني الخاص بك بأمر واحد

> على خادم صغير خارج بلدك، شغّل **أمرًا واحدًا** فيقوم تلقائيًا بجلب مئات المخارج المجانية من مصدر عقد عام (VPNGate)، ويقيس سرعتها الحقيقية، ويختار بذكاء أسرع خط، ثم يوفّر لك من الخارج بروكسي **SOCKS5 / HTTP** مستقرًّا. وعند انقطاع أي عقدة يتم التبديل تلقائيًا، دون أن تحتاج إلى مراقبته طوال الوقت.

**لمن هذا الأداة؟**

- من يريد مخرج بروكسي **خاصًّا به ويتحكّم فيه**، بدل تسليم بياناته لمزوّد آخر.
- من لديه (أو ينوي شراء) خادم VPS خارج بلده ويرغب في تحويله إلى بوابة بروكسي مؤتمتة بالكامل.
- من لا يريد التعامل مع إعدادات معقّدة — **يُثبَّت بأمر واحد، وبضع نقرات في الويب يصبح جاهزًا للاستخدام**.

## ✨ أبرز المزايا

- 🔌 **النشر بأمر واحد**: التبعيات والخدمة والتشغيل التلقائي عند الإقلاع، كلها تُنجَز آليًا، حتى المبتدئ يستطيع البدء.
- 🌍 **اكتشاف تلقائي + قياس سرعة حقيقي**: يجلب مئات العقد من مصدر عام، ويختبر فعليًا الاتصال والزمن، ويختار الأسرع تلقائيًا.
- ♻️ **تبديل تلقائي عند الانقطاع**: العقد المجانية غير مستقرة؟ يعيد الاتصال ويبدّل تلقائيًا في الخلفية ليبقى البروكسي متصلًا دائمًا.
- 🧩 **SOCKS5 / HTTP على المنفذ نفسه**: منفذ واحد `9527` يكفيهما معًا، ويُتعرَّف على البروتوكول تلقائيًا من أول بايت.
- 🖥️ **لوحة ويب خلفية بسيطة**: تجمّع العقد وحالة البوابة والسجلات والسياسات، كلها في شاشة واحدة.
- 📦 **ملف واحد بلا تبعيات**: ثنائي ساكن وحيد يضمّ الواجهة الأمامية وقاعدة البيانات داخله، يعمل فور نشره.

## ⚡ النشر بثلاث خطوات (نسخة المبتدئ حقًّا)

نفترض أنك اشتريت VPS بالفعل، وحصلت على **عنوان IP للخادم** و**كلمة مرور root**.

**الخطوة 1 · تسجيل الدخول إلى VPS عبر SSH**

```bash
ssh root@你的服务器IP
```

**الخطوة 2 · التثبيت بأمر واحد**

```bash
bash <(curl -Ls https://raw.githubusercontent.com/masteralanlab/free-proxy/main/install.sh)
```

سيقوم السكربت تلقائيًا بـ: تنزيل البرنامج المناسب لمعمارية جهازك ← تثبيت تبعيات النظام (openvpn وغيرها) ← تسجيل خدمة التشغيل التلقائي عند الإقلاع ← البدء. انتظر حتى ينتهي فقط، دون أي تفاعل طوال العملية.

**الخطوة 3 · الحصول على رابط الإدارة واسم المستخدم وكلمة المرور**

```bash
free-proxy credentials
```

سيطبع شيئًا شبيهًا بـ:

```text
URL: http://127.0.0.1:8787/xxxxxxxxxxxx/
Username: xxxxxxxx
Password: xxxxxxxx
```

## 🌐 كيف تستخدم البروكسي / تدخل إلى لوحة الويب الخلفية

تستمع الخدمة افتراضيًا على `0.0.0.0`، وتتضمّن **مفتاح «الوصول من الشبكة الخارجية»** (يمكن تبديله في أي وقت من صفحة «السياسات» في اللوحة، **ويسري فورًا دون إعادة تشغيل**). أما الوصول المحلي وعبر نفق SSH فيبقى **متاحًا دائمًا** ولا يتأثر بهذا المفتاح.

### لوحة الويب الخلفية: الوصول الخارجي مسموح افتراضيًا ✅

محميّة بحماية مزدوجة: تسجيل الدخول + مسار مفتاح عشوائي، فتفتحها من الشبكة الخارجية فور التثبيت. افتح في المتصفح العنوان الذي طبعه `free-proxy credentials`:

```text
http://你的服务器IP:8787/<你的安全路径>/
```

إن لم تكن بحاجة إلى الوصول العام، يمكنك إيقاف مفتاح الوصول الخارجي لها من اللوحة، أو استخدام نفق SSH بدلًا منه (انظر أدناه).

### منفذ البروكسي: محلي فقط افتراضيًا 🔒

لتجنّب تحوّله إلى **«بروكسي مفتوح»** يستطيع أي شخص استخدامه، يخدم البروكسي افتراضيًا الجهاز المحلي فقط. لاستخدامه من الشبكة الخارجية، خطوتان:

1. **اضبط كلمة مرور للبروكسي**: عدّل `/etc/free-proxy/free-proxy.env` وأضِف السطرين التاليين، ثم نفّذ `systemctl restart free-proxy`:
   ```text
   FREE_PROXY_PROXY_USERNAME=自己设一个用户名
   FREE_PROXY_PROXY_PASSWORD=自己设一个强密码
   ```
2. **فعّله من اللوحة**: ادخل إلى لوحة الويب «السياسات ← الوصول الخارجي»، وفعّل «السماح بالوصول الخارجي إلى منفذ البروكسي» ثم احفظ.

بعد ذلك يمكنك استخدامه في تطبيقات جهازك المحلي عبر: `socks5://用户名:密码@你的服务器IP:9527`.

> 🔒 أكثر استخدام محافظة (دون فتح الشبكة العامة إطلاقًا): أوقف الوصول الخارجي للوحة الويب من اللوحة، واستخدم نفق SSH بدلًا منه —
> `ssh -L 8787:127.0.0.1:8787 -L 9527:127.0.0.1:9527 root@你的服务器IP`، ثم افتح محليًا `127.0.0.1`.

### التحقق من أن البروكسي يعمل

```bash
curl --proxy socks5h://127.0.0.1:9527 https://api.ipify.org   # 返回的应是“VPN 出口 IP”,而不是你 VPS 自己的 IP
curl --proxy http://127.0.0.1:9527   https://api.ipify.org
```

إذا رأيت عنوان IP مختلفًا عن عنوان VPS الخاص بك، فهذا يعني أن البروكسي يوجّه حركتك عبر مخرج الـ VPN 🎉

## 🖱️ كيفية استخدام لوحة الويب الخلفية

1. افتح رابط الإدارة وسجّل الدخول باسم المستخدم وكلمة المرور.
2. اضغط **«تحديث واختبار العقد»**، وانتظر قليلًا حتى يكتشفها ويقيس سرعتها ويتصل تلقائيًا بأسرع عقدة.
3. تعرض لوحة **«البوابة»** العقدة المخرجة الحالية وزمن الاستجابة وعنوان IP للمخرج.
4. وجّه بروكسي تطبيقات جهازك المحلي إلى `127.0.0.1:9527` لتبدأ الاستخدام.

## ❓ الأسئلة الشائعة

- **لا يتصل / لا توجد عقد مؤقتًا؟** العقد المجانية (VPNGate) نفسها تتذبذب، والخدمة تعيد المحاولة والتبديل تلقائيًا. انتظر قليلًا، أو اضغط مرة واحدة على «تحديث واختبار العقد» في اللوحة.
- **تظهر رسالة تتطلب root / TUN؟** شغّله بصلاحية root، وتأكد من أن VPS مفعِّل لـ TUN/TAP. كلٌّ من **[BandwagonHost](https://cutt.ly/qywJNWzd)** / **[DMIT](https://cutt.ly/YywJIzY0)** بمعمارية KVM، وتدعمه افتراضيًا وجاهز فور الاستخدام.
- **هل خادم VPS الخاص بي بمعمارية ARM؟** لا داعي للقلق، فسكربت التثبيت يتعرّف تلقائيًا على amd64 / arm64.
- **هل أستطيع تشغيله على حاسوبي الشخصي (macOS/Windows)؟** يمكن بناؤه وتطويره، لكن النفق الحقيقي والبروكسي المخرج يحتاجان إلى Linux + root + TUN، فانشره على VPS.

## 🛡️ نصائح أمنية

- تستمع الخدمة افتراضيًا على `0.0.0.0`، ويتحكّم في مدى تعرّضها مفتاح «الوصول الخارجي» في اللوحة: **لوحة الويب مفتوحة افتراضيًا** (محميّة بتسجيل الدخول + مسار المفتاح)، و**البروكسي محلي فقط افتراضيًا**. عند عدم الحاجة إلى الوصول العام، يمكنك إيقاف الوصول الخارجي للوحة الويب من اللوحة واستخدام نفق SSH بدلًا منه.
- **يجب ضبط اسم مستخدم وكلمة مرور للبروكسي قبل تفعيل الوصول الخارجي إليه**، وإلا تحوّل إلى «بروكسي مفتوح» يستطيع أي شخص استخدامه، وهو عرضة لإساءة الاستخدام بشدة مما قد يؤدي إلى حظر VPS؛ ولهذا يرفض النظام كل طلبات البروكسي الخارجية ما دامت كلمة المرور غير مضبوطة.
- بعد أول تسجيل دخول، غيّر اسم مستخدم وكلمة مرور الإدارة في أقرب وقت. النفق وتوجيه السياسات وتثبيت التبعيات تحتاج إلى root، ففعّلها فقط على خادم تتحكّم فيه بنفسك.


### الإعداد

ملف الإعداد في بيئة الإنتاج هو افتراضيًا `/etc/free-proxy/free-proxy.env` (يُنشئه `free-proxy install`)، وتوحَّد متغيرات البيئة تحت البادئة `FREE_PROXY_`. تقرأ جميع الأوامر الفرعية هذا الملف تلقائيًا (متغيرات بيئة العملية لها الأولوية؛ ويمكن تجاوز المسار عبر `FREE_PROXY_ENV_FILE`). أهم الخيارات:

```text
FREE_PROXY_DATA_DIR=/var/lib/free-proxy
FREE_PROXY_WEB_PORT=8787
FREE_PROXY_PROXY_PORT=9527
FREE_PROXY_PROXY_ENABLED=true
FREE_PROXY_PROXY_USERNAME=
FREE_PROXY_PROXY_PASSWORD=
FREE_PROXY_OPENVPN_COMMAND=openvpn
FREE_PROXY_TUNNEL_INTERFACE=tun0
FREE_PROXY_UPSTREAM_PROXY_URL=
FREE_PROXY_DNS_REPAIR_ENABLED=false
```

> الاستماع مربوط ثابتًا بـ `0.0.0.0`؛ أما ما إذا كان مفتوحًا للشبكة الخارجية فيتحكّم فيه **مفتاح «الوصول الخارجي» في اللوحة** (لوحة الويب مفتوحة افتراضيًا، والبروكسي مغلق افتراضيًا)، ويسري في وقت التشغيل فورًا دون إعادة تشغيل. ضبط `FREE_PROXY_PROXY_USERNAME` / `PASSWORD` شرط لتفعيل الوصول الخارجي إلى البروكسي.

على خادم ضعيف الموارد (مثل نواة واحدة / 1 غيغابايت) يمكنك خفض حمل الفحص:

```text
FREE_PROXY_MAX_PROBE_CONCURRENCY=2
FREE_PROXY_DISCOVERY_LIMIT=60
FREE_PROXY_INITIAL_CONNECT_TEST_LIMIT=5
```

### ملخّص الـ API

جميع النقاط الطرفية تحت بادئة المسار الآمن: `/{secret_path}/api/v1/...`. تُعيد العمليات الطويلة `202 + Job`، ويُستطلَع عنها عبر `GET /jobs/{id}`.

```text
POST   /api/v1/auth/login        POST /api/v1/auth/logout
GET    /api/v1/auth/config       PUT  /api/v1/auth/credentials
GET    /api/v1/proxies           POST /api/v1/proxies/discover|refresh|probe
POST   /api/v1/proxies/{id}/probe|activate|favorite
GET    /api/v1/proxies/{id}/probes|config
GET    /api/v1/gateway/status    POST /api/v1/gateway/check|rotate    DELETE /api/v1/gateway/current
GET    /api/v1/pool/statistics   GET  /api/v1/jobs/{id}
GET    /api/v1/settings          PUT  /api/v1/settings
GET    /api/v1/system/status|diagnostics   POST /api/v1/system/dns/repair
GET    /api/v1/logs              GET  /api/v1/logs/export
```

### حزمة التقنيات

- **Go 1.23+**، وEcho v5 (الويب/API)، وsqlc + `modernc.org/sqlite` (Go خالص، دون CGO)، وgoose (هجرات مدمجة)، وcobra (سطر الأوامر)، وlog/slog.
- الواجهة الأمامية **React 19 + Vite + Tailwind v4 + Zustand**، ويُدمَج ناتج البناء داخل الثنائي عبر `//go:embed`.
- كلمات المرور مُجزّأة بـ `scrypt`، والمصادقة عبر مسار آمن عشوائي + كوكي الجلسة.


لعدم استخدام CGO، يمكنك إنتاج ثنائي Linux مباشرة على macOS. انسخ ناتج البناء المحلي إلى الجهاز الهدف ثم نفّذ `sudo ./free-proxy install` للنشر.

التحديث الحيّ أثناء التطوير:

```bash
cd frontend && bun install && bun run dev   # 前端热更新(配合下方 serve)
go run ./cmd/free-proxy serve                # 后端(首次会生成随机管理地址与密码)
```

### إصدار Release

يقوم `install.sh` بتنزيل `free-proxy-linux-{amd64,arm64}` من GitHub Releases، ويبنيه ويصدره تلقائيًا `.github/workflows/release.yml` عند **دفع وسم إصدار**:

```bash
git tag v1.0.0
git push origin v1.0.0      # 触发 Action:构建前端 + 交叉编译 → 发布 Release(含 SHA256SUMS)
```

يجب أن يبدأ الوسم بـ `v`. وبعد اكتمال الإصدار، يصيب تنزيل `latest` في `install.sh` هذا الثنائي.
